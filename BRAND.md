# HashHurdr brand

The code is MIT and free for everyone (see [LICENSE](LICENSE)). The name and artwork have a few friendly rules. The full policy is in [docs/brand/BRAND-POLICY.md](docs/brand/BRAND-POLICY.md), copied word for word from the HashHurdr brand kit v1.0.

## Official marks

The name HashHurdr, the wordmark, the logo and the app icon are used as supplied. Do not change, recolor or redraw them. Do not use them as the name or logo of a different product, or of a fork that changed the code. If you ship a fork, give it your own name and logo.

## Hashling and the other brand art

Hashling, the mascot, is free to share. Fan art, memes and videos are welcome; label them fan-made if they could pass as official. Stickers and shirts for fun or at cost are welcome. Selling them commercially needs permission: open an issue on the project page.

## Where the artwork lives here

Every file below is an unmodified copy from the brand kit.

- `web/public/brand/`: the symbol and the horizontal lockups shown in the app.
- `web/public/icons/`, `web/public/favicon.ico`, `web/public/favicon.svg`, `web/public/apple-touch-icon-180.png`: app icons and favicons.
- `installer/windows/hashhurdr.ico`: the Windows installer and program icon.
- `docs/brand/`: the README banners and the brand policy.

## What did not change

Only the display name changed. The package (`bitcoin-solo-miner-monitor`), the `bsmm` command and service names, data and key locations, API paths, the Docker image and the repository name stay as they were.
