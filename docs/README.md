# Documentation Structure

This directory contains all project documentation organized by category.

## Directory Structure

### 📁 `/bug-reports`
Contains detailed bug diagnostic reports and solution plans.
- Bug analysis and root cause investigations
- Solution implementation plans
- Post-fix verification reports

### 📁 `/investigations`
Contains investigation reports for complex issues and system behavior analysis.
- Root cause analysis documents
- System behavior investigations
- Performance analysis reports

### 📁 `/development`
Contains development-related documentation and guides.
- Development mode guides
- Debug enhancement plans
- Development chat summaries and notes

### 📁 `/implementation-reports`
Contains detailed reports of feature implementations and fixes.
- Feature implementation summaries
- Bug fix reports
- System enhancement documentation

### 📁 `/implementation-summaries`
Contains high-level summaries of major implementations.
- Security implementation summaries
- Architecture change summaries
- Major feature overviews

### 📁 `/build`
Contains build system documentation.
- Build environment setup
- Reproducible build guides
- Community build verification

### 📁 `/community`
Contains community-related documentation.
- Contribution guides
- Community metrics
- Feedback processes

### 📁 `/distribution`
Contains distribution and packaging documentation.
- Package maintainer guides
- Distribution partnerships
- Package submission guides

### 📁 `/installation`
Contains installation guides for all platforms.
- Windows installation
- macOS installation
- Linux installation
- Troubleshooting guides

### 📁 `/security`
Contains security-related documentation.
- Security audit guides
- Security issue reporting
- Security best practices

## Root-Level Documentation

- `API_SECURITY.md` - API security guidelines
- `BUILD.md` - Build instructions
- `DEPLOYMENT_CHECKLIST.md` - Deployment checklist
- `TESTING_GUIDE.md` - Testing guidelines
- `user-guide.md` - End-user documentation

## Note for Releases

Development-only folders (`bug-reports/`, `investigations/`, `development/`) are excluded from release builds via `.gitignore`. These folders are for internal development tracking and are not needed by end users.
